# 方案A：经典RPG风格 - 复古魔法书

## 1. 方案名称和设计理念
**方案名称：** 魔法典籍（Grimoire Codex）  
**设计理念：** 致敬经典RPG游戏，以魔法书、羊皮纸、古老符文为核心视觉元素，营造出神秘、古老、厚重的魔法世界氛围。强调"翻开魔法书"的沉浸感，让玩家感觉自己是一位正在探索古老法术的魔法师。

## 2. 主菜单设计
**布局：**
- 背景：一本翻开的古老魔法书，书页微微泛黄，边缘有烧焦的痕迹
- 标题"秘法回响"以哥特式花体字呈现，镶嵌在书本上方
- 菜单选项（开始游戏、设置、退出等）以羊皮纸卷轴形式排列在书页左侧
- 右侧书页展示游戏场景或角色原画

**配色：**
- 主色调：深棕色（#8B4513）、古铜色（#CD853F）、暗红色（#8B0000）
- 辅助色：象牙白（#FFFFF0）、金色（#DAA520）
- 强调色：魔法蓝（#4169E1）

**按钮风格：**
- 羊皮纸质感按钮，边缘有撕裂效果
- 悬停时按钮微微发光，发出古老魔法光芒
- 点击时书页翻动动画

## 3. 游戏内HUD设计
**血量（生命值）：**
- 显示为一个古老的魔法瓶，内有红色液体
- 位置：左上角
- 受伤时液体晃动，低血量时瓶子出现裂痕

**法术槽：**
- 显示为5个古老的魔法符文石
- 位置：屏幕下方中央
- 冷却中时符文石变暗，可用时发出光芒
- 法术图标采用手绘羊皮纸风格

**经验条：**
- 显示为卷轴展开的形式
- 位置：屏幕下方，法术槽下方
- 经验增加时卷轴从左向右展开，带有金色粒子效果

**时间显示：**
- 显示为沙漏或古老时钟
- 位置：右上角
- 沙漏中的沙子代表剩余时间

**其他元素：**
- 分数显示：古老的金币堆
- 金币显示：散落的金币图标
- 敌人计数：骷髅头标志+数字

## 4. 升级选择界面设计
- 整个界面为一本打开的魔法书
- 三个升级选项以羊皮纸卡片形式展示
- 每个卡片上有手绘的魔法图标和说明文字
- 卡片边缘有蜡封装饰
- 选择时卡片会发光并浮起，未选择的卡片逐渐变暗
- 背景有飘动的魔法符文粒子

## 5. 整体配色方案
**主色板：**
- 深棕色：#8B4513（背景、主要元素）
- 古铜色：#CD853F（按钮、边框）
- 暗红色：#8B0000（血量、重要元素）
- 象牙白：#FFFFF0（文字、高亮）
- 金色：#DAA520（装饰、奖励元素）
- 魔法蓝：#4169E1（法术、魔法效果）

**辅助色：**
- 墨绿色：#2E8B57（生命、自然魔法）
- 暗紫色：#483D8B（神秘、暗影魔法）

## 6. 字体风格建议
- **标题字体：** 哥特式花体字（如：Uncial Antiqua, MedievalSharp）
- **正文字体：** 古典衬线体（如：Cinzel, Trajan Pro）
- **数字字体：** 罗马数字风格或古典数字字体
- **中文字体：** 方正清刻本悦宋、汉仪全唐诗体等具有古典韵味的字体

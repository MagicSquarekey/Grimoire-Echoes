## العربية

![version](https://img.shields.io/badge/version-v0.0.1-gold) ![engine](https://img.shields.io/badge/Godot-4.7-blue) ![platform](https://img.shields.io/badge/platform-Windows-purple) ![license](https://img.shields.io/badge/license-CC0-green)

**صدى السِّحر (Grimoire Echoes / 秘法回响)** لعبة أكشن روجولايت بأسلوب ألعاب البقاء على قيد الحياة (survivors-like)، تعمل محليًا للاعب واحد. العب في دور سحّاء يتحكمون بقوى العناصر، صمد أمام جحافل مخلوقات الظلام، وابتكر تركيبات تعاويذ فريدة من خلال دمج العناصر.

### 🎮 أسلوب اللعب الأساسي

- **تعاويذ تلقائية + تحكّم يدوي في الحركة**: تُطلق التعاويذ المُجهَّزة تلقائيًا، وأنت تركّز على التهرّب والالتقاط
- **ستة عناصر**: 🔥 النار / ❄️ الجليد / ⚡ البرق / 🌿 الطبيعة / 💀 الظل / ✨ الأسرار
- **دمج العناصر**: جهّز تعاويذ من عناصر مختلفة لتفعيل **15 تعويذة اندماج** (انفجار البخار، القنبلة اللهبية المظلمة، العاصفة الثلجية…)
- **تقدّم روجولايت**: ترقيات بثلاثة خيارات بمراتب (عادي / نادر / ملحمي / أسطوري)، و12 تعزيزًا في المتجر، ونظام الآثار
- **موجات الأحداث**: صناديق كنوز نادرة، مذابح ملعونة (تُبادل الدم بالقوة)، ونخب بمكافآت
- **وضع زحف الزعماء (Boss Rush)**: تحدٍّ بلا نهاية من معارك الزعماء تتزايد صعوبته
- **ثلاثة سحرة**: ساحر النار (انفجاري) / ساحر الماء (تحكّم) / ساحر البرق (سرعة فائقة)

### 🕹️ التحكّم

| المفتاح | الوظيفة |
|---------|---------|
| `WASD` | الحركة |
| `Shift` | التهرّب (لحظات مناعة) |
| `E` | الالتقاط / التفاعل |
| `C` | لوحة الخصائص |
| `ESC` | الإيقاف المؤقت / مغادرة المتجر |
| `Tab` / `M` | تبديل سرعة اللعبة |

### 🛠️ التشغيل

```bash
# يتطلّب Godot 4.7 أو أحدث (https://godotengine.org/download)
git clone https://github.com/MagicSquarekey/Grimoire-Echoes.git
cd Grimoire-Echoes/game
# افتح project.godot في محرر Godot ثم اضغط F5
```

أو نزّل نسخة Windows الجاهزة من صفحة الإصدارات (Releases)، وفكّ الضغط عنها والعب مباشرة.

### 🧰 أبرز الخصائص التقنية

- **خط المعالجة (Render pipeline)**: نماذج KayKit CC0 عالية التفاصيل → تقسيم الشبكة ×2 → إعادة بناء النظم السلسة → إضاءة استوديو ثلاثية النقاط → تصيير بترشيح فائق بدقّة 512px
- **الأجواء**: إضاءة 2D ديناميكية، توهّج HDR، تصحيح لوني لكامل الشاشة، وغبار سحري يُولَّد إجرائيًا
- **الصوت**: 22 مؤثرًا صوتيًا مُركّبًا برمجيًا بالكامل (موجات جيبية/منشارية/تشويش + انزلاق في الطبجة + أغلفة زمنية)
- **الاختبارات**: 8 مجموعات اختبار آلية (وحدات / دخان مشاهد / كافّة التعاويذ / انحدار وظيفي / إجهاد / محاكاة مستخدم)

## 日本語

![version](https://img.shields.io/badge/version-v0.0.1-gold) ![engine](https://img.shields.io/badge/Godot-4.7-blue) ![platform](https://img.shields.io/badge/platform-Windows-purple) ![license](https://img.shields.io/badge/license-CC0-green)

**グリモワール・エコーズ（秘法回响）** はシングルプレイ対応のローカル・サバイバーライクローグライトアクションゲームです。元素魔法を操る魔法使いとなり、闇の生物の群れを生き延び、元素融合で独自のスペル構成を作り上げ、爽快な弾幕バトルを体験しましょう。

### 🎮 コアゲームプレイ

- **自動詠唱 + 手動回避**：装備したスペルは自動発動 — プレイヤーは回避と回収に集中
- **6つの元素**：🔥 火 / ❄️ 氷 / ⚡ 雷 / 🌿 自然 / 💀 影 / ✨ 秘術
- **元素融合**：異なる元素のスペルを装備すると **15種の融合スペル** が解放（蒸気爆発、暗黒炎、吹雪…）
- **ローグライト成長**：3択アップグレード（コモン/レア/エピック/レジェンダリー品質）、12種のショップ強化、 relic システム
- **イベントウェーブ**：宝箱、呪われた祭壇（HPと引き換えに強化）、賞金首エリート
- **ボスラッシュモード**：際限なく強くなるボス連戦
- **3人の魔法使い**：火の魔道士（爆発）/ 水の魔道士（制御）/ 雷の魔道士（速度）

### 🕹️ 操作方法

| キー | 操作 |
|------|------|
| `WASD` | 移動 |
| `Shift` | 回避（無敵フレーム） |
| `E` | 拾取 / インタラクト |
| `C` | ステータスパネル |
| `ESC` | ポーズ / ショップ退出 |
| `Tab` / `M` | ゲーム速度切替 |

### 🛠️ 実行方法

```bash
# Godot 4.7+ が必要 (https://godotengine.org/download)
git clone https://github.com/MagicSquarekey/Grimoire-Echoes.git
cd Grimoire-Echoes/game
# Godot エディタで project.godot を開き F5 を押す
```

または Releases ページの Windows ビルドをダウンロードして解凍するだけで遊べます。

### 🧰 技術的特徴

- **レンダリングパイプライン**：KayKit CC0 高精細モデル → メッシュ細分化 ×2 → スムーズ法線再構築 → 三点スタジオ照明 → 512px スーパーサンプリング
- **演出**：動的2Dライティング、HDRグロー、全画面カラーグレーディング、プログラム生成的秘法粒子
- **オーディオ**：22音効を全て合成（正弦/鋸歯/ノイズ + ピッチスライド + エンベロープ）
- **テスト**：8種の自動テストスイート（ユニット / シーンスモーク / 全スペル / 機能回帰 / ストレス / ユーザーシミュレーション）

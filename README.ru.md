## Русский

![version](https://img.shields.io/badge/version-v0.0.1-gold) ![engine](https://img.shields.io/badge/Godot-4.7-blue) ![platform](https://img.shields.io/badge/platform-Windows-purple) ![license](https://img.shields.io/badge/license-CC0-green)

**Гримуар Эхо** — это локальная однопользовательская Action-Roguelite в духе survivors-like. Примерте роль мага стихий, выживайте против полчищ тёмных созданий, собирайте уникальные заклинательные сборки через слияние стихий и наслаждайтесь бешеными «пулевыми» боями.

### 🎮 Основной геймплей

- **Автокаст + ручное уклонение**: надетые заклинания срабатывают сами — вы сосредотачиваетесь на уклонении и сборе
- **Шесть стихий**: 🔥 огонь / ❄️ лёд / ⚡ молния / 🌿 природа / 💀 тень / ✨ тайная магия
- **Слияние стихий**: надевайте заклинания разных стихий, чтобы открыть **15 заклинаний слияния** (паровой взрыв, тёмное пламя, метель…)
- **Roguelite-прогрессия**: апгрейды с выбором из трёх по редкости **обычный / редкий / эпический / легендарный**, 12 улучшений в магазине, волны случайных событий
- **Волны событий**: сундуки с сокровищами, проклятые алтари (здоровье в обмен на силу), элита за голову
- **Режим цепочки боссов**: бесконечная череда боя с боссами, которые усиливаются без предела
- **Три мага**: мастер огня (взрывной урон) / мастер воды (контроль) / мастер молнии (скорость)

### 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| `WASD` | Перемещение |
| `Shift` | Уклонение (кадры неуязвимости) |
| `E` | Поднять / взаимодействовать |
| `C` | Панель характеристик |
| `ESC` | Пауза / выход из магазина |
| `Tab` / `M` | Переключение скорости игры |

### 🛠️ Запуск

```bash
# Требуется Godot 4.7+ (https://godotengine.org/download)
git clone https://github.com/MagicSquarekey/Grimoire-Echoes.git
cd Grimoire-Echoes/game
# Откройте project.godot в редакторе Godot и нажмите F5
```

Или скачайте готовую сборку для Windows со страницы Releases — распакуйте и играйте.

### 🧰 Технические особенности

- **Конвейер рендеринга**: высокодетализированные CC0-модели KayKit → подразделение сетки ×2 → перестройка сглаженных нормалей → трёхточечный студийный свет → рендер с суперсэмплингом 512 px
- **Атмосфера**: динамическое 2D-освещение, HDR-свечение, полноэкранная цветокоррекция, процедурные тайные искры света
- **Аудио**: 22 полностью синтезированных звуковых эффекта (синус / пила / шум + скольжение высоты + огибающие)
- **Тесты**: 8 автоматизированных наборов тестов (модульные / дымовые по сценам / все заклинания / регрессия функций / нагрузка / симуляция пользователя)

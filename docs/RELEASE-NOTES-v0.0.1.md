# 🎉 Grimoire Echoes v0.0.1 — First Release

**秘法回响 · Grimoire Echoes** 首个公开测试版本发布！一款单人本地、Godot 4 引擎打造的类幸存者肉鸽动作游戏。

**First public preview build.** A single-player, local survivors-like roguelite action game made with Godot 4.

---

## 📦 下载 / Downloads

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `GrimoireEchoes-v0.0.1-windows.zip` | 解压后运行 `GrimoireEchoes-v0.0.1-windows.exe` |

> 源码运行：`cd game` → Godot 4.7+ 打开 `project.godot` → F5
> Source: open `game/project.godot` in Godot 4.7+ and press F5.

---

## ✨ 首发内容 / What's Included

- 🧙 **三位法师**：火焰（爆发）/ 水流（控制）/ 雷电（极速）
- 🔥❄️⚡🌿💀✨ **六元素 × 45+ 法术**，含 **15 种元素融合**（蒸汽爆炸、暗焰爆弹、暴风雪…）
- 👹 **6 种敌人 + 7 种精英词缀** + 多阶段 Boss
- 🎁 **局内事件波**：宝箱 / 诅咒祭坛 / 悬赏精英
- ⚔️ **Boss 连战模式**：无尽 Boss 挑战
- 🎴 **升级品阶**：普通 / 稀有 / 史诗 / 传说
- 🏪 **商店系统**：12 种强化，可重复购买
- 📊 **属性面板**：游戏内 `C` 键 / 暂停菜单
- 🎨 **渲染管线**：KayKit CC0 高模 → 网格细分 → 三点灯光 → 512px 超采样 + 动态 2D 光照 + HDR 辉光 + 全屏调色
- 🔊 **22 个程序化合成音效**
- 🕹️ **操作**：WASD 移动 / Shift 闪避 / E 互动 / C 属性 / ESC 暂停 / Tab 变速

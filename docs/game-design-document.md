│  │  波次 1-5:   敌人稀疏，学习法术操作                          │ │
│  │  波次 6-10:  敌人增多，第一次精英怪                           │ │

### 1.2 单局时长目标

| 阶段 | 波次数 | 预计时长 | 累计时长 |
|------|--------|----------|----------|
| 开局探索 | 1-10 | ~5 分钟 | 5 分钟 |
| 中期成长 | 11-25 | ~10 分钟 | 15 分钟 |
| 高潮战斗 | 26-45 | ~15 分钟 | 30 分钟 |
| 终局 Boss | 46-50 | ~5 分钟 | 35 分钟 |
| **完整一局** | **50 波** | **~35 分钟** | **35 分钟** |

- **短局目标：** 30-40 分钟（正常通关）
- **快节奏模式：** 20 分钟（解锁后可选，波次减半，敌人强度不变）

### 1.3 死亡惩罚机制

**设计哲学：** 死亡不是惩罚，是学习。

| 机制 | 说明 |
|------|------|
| **即时重开** | 死亡后一键重开，无等待、无惩罚 |
| **记忆解锁** | 每次死亡后，解锁"法术图鉴"中 1 条新信息（法术组合提示/敌人弱点） |
| **成就追踪** | 死亡不影响成就和图鉴进度 |
| **统计保留** | 死亡局的数据计入"总统计"（总击杀、总法术使用次数等） |
| **无资源惩罚** | 不扣金币、不扣经验、不扣任何东西 |

**死亡后的记忆解锁系统：**
```
死亡次数 → 解锁内容
第1次    → 法术图鉴：解锁1条元素融合配方提示
第2次    → 敌人图鉴：解锁1个敌人行为模式描述
第3次    → 法术图鉴：解锁1个法术升级路线提示
第5次    → 遗物图鉴：解锁1个遗物效果描述
第10次   → 解锁"契约"系统的完整说明
第20次   → 解锁所有图鉴内容（不再有隐藏信息）
```

### 1.4 胜利条件

| 胜利类型 | 条件 | 奖励 |
|----------|------|------|
| **普通胜利** | 击败第50波最终Boss | 解锁下一张地图 + 结算画面 |
| **完美胜利** | 不死亡通关 | 额外1个遗物选择权 |
| **挑战胜利** | 完成特定契约条件通关 | 解锁新契约 |
| **隐藏胜利** | 触发特殊条件（如：用纯火元素通关） | 解锁隐藏法术 |

### 6.3 法术伤害公式

**基础伤害公式：**
```
实际伤害 = 基础伤害 × 法术等级倍率 × 攻击力倍率 × 元素亲和加成 × 暴击倍率 × 遗物加成 × 契约惩罚
```

#### 各乘数说明

| 乘数 | 公式 | 说明 |
|------|------|------|
| 基础伤害 | 固定值 | 每个法术的基础伤害值 |
| 法术等级倍率 | 1.0 + (等级-1) × 0.08 + 质变加成 | 等级1-20的伤害倍率 |
| 攻击力倍率 | 角色基础攻击力 × (1 + 攻击力提升%) | 角色属性和被动加成 |
| 元素亲和加成 | 1.0 + 元素亲和% | 对应元素加成 |
| 暴击倍率 | 1.0 (非暴击) / 暴击伤害% (暴击时) | 暴击时的伤害倍率 |
| 遗物加成 | 1.0 + 遗物效果% | 遗物提供的伤害加成 |
| 契约惩罚 | 1.0 / (1 + 契约敌人生命加成%) | 契约对敌人生命的加成 |

#### 计算示例

**场景：** 火焰法师，Lv.10火球术，有火焰亲和+10%，暴击，有火焰徽记+8%

```
基础伤害 = 55 (Lv.10火球术)
法术等级倍率 = 2.20
攻击力倍率 = 1.2 × (1 + 0.15) = 1.38 (假设攻击力提升15%)
元素亲和加成 = 1.10
暴击倍率 = 1.50
遗物加成 = 1.08

实际伤害 = 55 × 2.20 × 1.38 × 1.10 × 1.50 × 1.08
         = 55 × 2.20 × 1.38 × 1.10 × 1.50 × 1.08
         ≈ 290 伤害
```

## 一、现状关键结论（计划依据）

| 发现 | 证据 | 影响 |
|------|------|------|
| 音频文件数为 0 | `assets/audio/music/`、`sfx/` 均为空目录 | AudioManager 已就绪，缺的是资产和接入，是最高性价比短板 |
| 敌人数据表已有 18 条，但 abilities 全空 | `scripts/enemies/enemy_generator.gd` E1-B3 | 治疗者/护盾守卫/自爆虫/分裂等特色行为**只有描述没有实现**，怪物扩容应先补行为再加新怪 |
| 只有 6 种敌人有专属脚本/场景 | `scripts/enemies/` + `scenes/enemies/` | 其余敌人靠 enemy_base 通用逻辑跑，表现同质化 |
| Boss 是通用数值怪 | B1-B3 仅 hp/dmg/速度差异，无阶段状态机 | Boss 战缺记忆点，需求文档的 4 地图 Boss 未落地 |
| 自动瞄准疑似逐法术遍历全场景敌人 | 法术脚本普遍 `get_tree().get_nodes_in_group("enemies")` | 后期大波次 + 多法术下是性能热点，需空间网格 |
| 已有压测/冒烟测试基建 | `tests/stress_test.gd`、`smoke_test_all_scenes.gd` | 性能优化有现成验证手段 |
| 设置菜单只有总音量一个滑条 | `settings_menu.gd` | 需补音乐/音效分离、画面、持久化 |
| 存档只有槽位 + 高分榜 | `save_manager.gd` | 无成就、无元进度、无局外解锁，留存缺钩子 |
| 精灵生成流水线已存在 | `tools/render_sprites.gd` + `assets/sprites/gen/` | 新怪物美术可复用流水线，成本低 |
| 仓库混入编辑器缓存与大量生成图改动 | git status | 需要提交策略与 .gitignore 治理 |

## Phase 2 · 战斗手感与性能（~1.5 周）

### 2.1 打击感包（割草爽感的一半）
| 手段 | 实现要点 |
|------|---------|
| 受击白闪 | enemy_base 受击时 Shader/Modulate 闪白 0.05s |
| Hitstop | 大额伤害/暴击/击杀精英时 `Engine.time_scale` 短暂降到 0.05（60-90ms），封装成 CombatManager 接口防滥用 |
| 屏幕震动 | Camera2D shake，按伤害档位分级，设置里可关 |
| 击退统一 | 所有法术/武器走统一的 knockback 通道，带质量抗性（Boss 免击退） |
| 死亡反馈 | 敌人死亡粒子 + 尸体溶解动画（现有 ObjectPool 复用） |
| 验收 | 用火球 + 连锁闪电连招对比改造前后录屏，主观"爽感"评审通过 |

### 2.2 性能：空间网格与上限（为 Phase 3 铺路）
- 新建 `SpatialGrid`（均匀网格，格子 ~128px），敌人生成/死亡注册注销，提供 `query_nearest(pos, radius)` / `query_circle()` / `query_fan()`
- 全部法术的"找最近敌人/范围内敌人"改走 SpatialGrid，消灭 `get_nodes_in_group` 全表遍历
- 同屏敌人/投射物/伤害数字上限 + 超限策略（远处怪不生成、旧伤害数字合并）
- 屏幕外敌人：降频 update（每 3 帧一次 AI 决策）
- 用 `tests/stress_test.gd` 建基线：**目标 500 同屏敌人 @ 60fps（1080p）**
- 验收：压测报告前后对比入档 `docs/perf-baseline-v2.md`

## 六、第二轮增补实施记录（2026-09-11，已全部完成 ✅）

用户从「单机深化候选清单」中挑选 5 项，本轮全部实施并测试通过：

### 6.1 ESC 暂停修复 ✅
- **根因**：`pause_menu.tscn` 根节点 `process_mode = 2`（WHEN_PAUSED）——未暂停时收不到输入，导致战斗中按 ESC 完全无响应；而商店/升级期间（树已暂停）又能响应，把暂停菜单开到商店图层（layer 10）之下形成"隐形暂停"。
- **修复**：pause_menu 重构为 `CanvasLayer(layer=20, process_mode=ALWAYS)`；`_unhandled_input` 集中路由——结算/结束画面打开时忽略、升级三选一期间屏蔽、**商店营业中 ESC=离开商店**、设置菜单打开时 ESC=关闭设置回到暂停菜单。
- **顺带修复**：暂停菜单「设置」按钮原为 `pass` 空实现 → 已接通游戏内 SettingsMenu 实例；shop/settings 增加公共 `close_shop()`/`close_settings()`。

### 6.2 升级三选一重投 ✅
- UpgradePanel 底部新增「🔄 重投」按钮：首次 20 金币，每次翻倍（20→40→80…），面板关闭后重置；金币不足自动置灰。
- 选项刷新走 player 的强化池生成器（`_generate_options(3)`），扣除金币走 GameManager/EventBus 金币通道。

### 6.3 Boss Rush 连战模式 ✅

- 波次计划：每波纯 Boss，数量每 3 波 +1（1,1,1,2,2,2,3…封顶 4），Boss 体型随波次缓慢成长（封顶 3.0），难度仍吃波次系数；无小怪无精英、无事件波。
- 波次横幅显示「⚠ Boss 连战 · 第 N 战」；死亡结算「再度唤醒」重生后保持连战模式。
